# Длительность поездки такси в Нью-Йорке

Регрессия для предсказания длительности поездки на такси в Нью-Йорке по
месту и времени посадки/высадки, на основе датасета соревнования Kaggle
«New York City Taxi Trip Duration» (~1,46 млн поездок). Базовые данные о
поездках дополнены маршрутными данными OSRM, почасовой погодой и
календарём праздников. Сравниваются шесть моделей (линейная регрессия,
полиномиальная регрессия + Ridge, дерево решений, случайный лес, градиентный
бустинг), метрика — **RMSLE** (родная метрика соревнования). Это самый
тяжёлый проект в портфолио (~900 МБ данных локально).

## Задача

Насколько точно можно предсказать длительность поездки такси по месту
посадки, месту высадки и времени посадки — и какие факторы (расстояние,
время суток, погода, маршрут) важнее всего? Такая оценка полезна для
прогноза времени прибытия и ценообразования.

## Данные

`train.csv` (записи о поездках) + `osrm_data_train.csv` (маршрут/расстояние)
+ `weather_data.csv` + `holiday_data.csv`, суммарно ~900 МБ, не хранятся в
git. Подробности — в [`data/README.md`](data/README.md).

## Что сделано

1. **Загрузка и обогащение данных**: признаки времени посадки, маршрут OSRM
   (`total_distance`, `total_travel_time`), погода (температура, осадки,
   условия), флаги праздников.
2. **EDA**: распределения длительности поездки, географические паттерны
   посадки/высадки, временные паттерны.
3. **Отбор и преобразование признаков**: `SelectKBest`/`f_regression` для
   отбора, `OneHotEncoder`/`MinMaxScaler`/`PolynomialFeatures` для
   преобразования; таргет — в логарифмической шкале (`log1p`), обратное
   преобразование `expm1` при инференсе (тот же приём, что и во флагманском
   проекте по недвижимости).
4. **Линейные модели и деревья**: линейная регрессия, полиномиальные
   признаки + линейная регрессия, Ridge, дерево решений с подбором глубины.
5. **Ансамбли**: случайный лес, градиентный бустинг (выбран лучшей моделью),
   анализ важности признаков, оценка по медианной абсолютной ошибке,
   предсказание на отложенных данных для отправки на Kaggle.

## Результаты

| Модель | RMSLE (train) | RMSLE (validation) |
|---|---|---|
| Линейная регрессия | 0,53 | 0,54 |
| Полиномиальная (степень 2) + линейная регрессия | 0,46 | 0,49 |
| Ridge (полиномиальные признаки, α=1,0) | 0,47 | 0,48 |
| Дерево решений (без ограничения глубины) | 0,00 (переобучение) | 0,56 |
| Дерево решений (глубина подобрана, optimal depth=12) | 0,40 | 0,43 |
| Случайный лес (`n_estimators=200, max_depth=12`) | 0,40 | 0,41 |
| **Градиентный бустинг (`lr=0.5, n_estimators=100, max_depth=6`)** | **0,37** | **0,39 (лучший)** |

**Лучшая модель — градиентный бустинг**, RMSLE 0,39 на валидации.
Медианная абсолютная ошибка (лучшая модель, валидация): **1,8 минуты**.

**Топ-3 признака по важности** (по модели градиентного бустинга):
`total_distance` (0,628), `total_travel_time` (0,187), `pickup_hour`
(0,059) — маршрутное расстояние и время от OSRM доминируют, час посадки —
далёкий третий. Погода и праздники присутствуют в модели, но не входят в
топ-3.
