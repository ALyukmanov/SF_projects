# Данные — сегментация клиентов (RFM)

## Источник

`customer_segmentation_project.csv` — датасет Online Retail (UCI Machine
Learning Repository): транзакции британского интернет-магазина без
физических точек продаж, ~541 909 строк, период с 2010-12-01 по
2011-12-09, кодировка `ISO-8859-1`.

## Схема (по факту данных)

| Столбец | Описание |
|---|---|
| `InvoiceNo` | Номер счёта; 6-значный код, с префиксом `C`, если это отмена |
| `StockCode` | Код товара |
| `Description` | Название товара |
| `Quantity` | Количество единиц в строке транзакции |
| `InvoiceDate` | Дата и время транзакции |
| `UnitPrice` | Цена за единицу, £ |
| `CustomerID` | Идентификатор клиента (есть пропуски — строки без `CustomerID` нельзя привязать к клиенту, удаляются перед агрегацией RFM) |
| `Country` | Страна клиента |

## Производные файлы

- `cleaned_data.zip` — **не второй входной датасет**, а сжатый CSV
  (`cleaned_data.csv` внутри архива), который сам ноутбук записывает по ходу
  выполнения как промежуточную контрольную точку очищенной таблицы
  транзакций перед агрегацией RFM. Это регенерируемый артефакт, отдельно
  получать его не нужно.

Файлы не входят в репозиторий.
