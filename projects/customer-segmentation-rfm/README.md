# Сегментация клиентов: RFM, кластеризация и классификатор сегмента

Сегментация клиентов интернет-магазина в Великобритании по классической
модели **RFM** (Recency, Frequency, Monetary), рассчитанной по ~500 тыс.
строк транзакций. Проект не ограничивается одним проходом RFM: строится
сегментация в пространстве PCA (3 сегмента), затем более детальная
сегментация в пространстве t-SNE (маркетингу нужно было больше 3 уровней),
а поскольку t-SNE не умеет обрабатывать новых клиентов, дополнительно
обучается классификатор (случайный лес / градиентный бустинг) на исходных
RFM-признаках, чтобы определять сегмент клиента без повторного запуска всего
пайплайна.

## Задача

Как сгруппировать клиентов интернет-магазина по покупательской способности,
частоте заказов и давности последней покупки в практичные маркетинговые
сегменты («лояльные», «под риском», «потерянные») — и, что важно, как
отнести к сегменту нового клиента без повторного прогона всей кластеризации.

## Данные

Экспорт транзакций британского интернет-магазина, ~542 тыс. строк, период с
2010-12-01 по 2011-12-09, агрегирован до одной RFM-строки на `CustomerID`.
Не хранится в репозитории — см. [`data/README.md`](data/README.md).

## Что сделано

1. **Построение RFM-таблицы**: группировка транзакций по `CustomerID`;
   `Recency` — дни с последней покупки относительно даты на день позже
   последней транзакции в датасете (2011-12-10); `Frequency` — число
   заказов; `Monetary` — сумма трат.
2. **Удаление выбросов**: убраны клиенты выше 95-го перцентиля по
   `Frequency` (>13 заказов) или `Monetary` (>£5 628,15) — с 4 334 до 4 044
   клиентов. `KMeans` чувствителен к выбросам, отсечение по 95-му перцентилю
   сохраняет большинство клиентов, убирая длинный хвост, который иначе
   перетягивал бы на себя центры кластеров.
3. **Сегментация №1 (PCA + 3 кластера)**: `StandardScaler` + `PCA(2
   компоненты)` в одном Pipeline (без утечки — параметры масштабирования
   берутся только из обученного пайплайна). PC1 объясняет 68% дисперсии,
   PC2 — 24% (92% суммарно). `KMeans` и `GaussianMixture` перебирались по
   k=2–10 по силуэтному коэффициенту; побеждает `KMeans` при **k=3**
   (силуэт 0,5452 против лучшего результата `GaussianMixture` 0,4624 при
   k=3). Профили сегментов: «лояльные» (776 клиентов, Recency 32 / Frequency
   7,1 / £2 657), «промежуточные» и «потерянные» (Recency 253 / Frequency
   1,4 / £386).
4. **Сегментация №2 (t-SNE + больше кластеров)**: после запроса от
   маркетинга на больше 3 уровней — `StandardScaler` + `TSNE` (2
   компоненты, perplexity 50, KL-дивергенция 0,54), затем повторный перебор
   `KMeans`, `GaussianMixture`, `AgglomerativeClustering` по k=3–8.
   Побеждает `KMeans` при **k=8** (силуэт 0,4948 против 0,4791 у
   `AgglomerativeClustering` при k=8 и 0,4683 у `GaussianMixture` при k=4) —
   7 заполненных маркетинговых сегментов (от «лояльных» до «спящих»).
5. **От кластеризации к классификатору**: t-SNE не параметрический — не
   умеет пересчитать положение нового клиента в том же пространстве
   постфактум, поэтому обучен классификатор напрямую на исходных
   RFM-признаках (не на t-SNE-эмбеддинге) для предсказания сегмента новых
   клиентов. Разбиение 80/20 (тестовая выборка — 809 клиентов).
   `RandomForestClassifier` и `GradientBoostingClassifier`, подбор каждого —
   5-фолдовый `GridSearchCV` по accuracy.

## Результаты

| Этап | Результат |
|---|---|
| RFM-таблица (до удаления выбросов) | 4 334 клиента |
| RFM-таблица (после удаления выбросов) | 4 044 клиента (убрано 290) |
| Объяснённая дисперсия PCA | PC1 68%, PC2 24%, всего 92% |
| Кластеризация №1 (пространство PCA) | `KMeans`, k=3, силуэт **0,5452** |
| Профили сегментов №1 | Лояльные: Recency 32д / Freq 7,1 / £2 657 (776 клиентов) · Промежуточные: Recency 51д / Freq 2,3 / £660 · Потерянные: Recency 253д / Freq 1,4 / £386 |
| t-SNE эмбеддинг | KL-дивергенция 0,54 |
| Кластеризация №2 (пространство t-SNE) | `KMeans`, k=8, силуэт **0,4948** (7 заполненных сегментов) |
| Классификатор сегмента — случайный лес | Accuracy на тесте **0,98** (`criterion='entropy'`, `max_depth=11`, `n_estimators=500`) |
| Классификатор сегмента — градиентный бустинг | Accuracy на тесте **0,98** (`learning_rate=0.1`, `max_depth=3`, `n_estimators=200`) |

Оба ансамблевых классификатора выходят на accuracy 0,98 при определении
сегмента напрямую по RFM-признакам — сегмент нового клиента можно получить
быстрым вызовом `predict()` вместо повторного запуска PCA/t-SNE и
кластеризации.

Интерактивные графики сравнения распределений Recency/Frequency/Monetary до
и после отсечения выбросов — в `assets/rfm_boxplots_before_outlier_removal.html`
и `assets/rfm_boxplots_after_outlier_removal.html` (открываются в браузере).
