# Данные — классификация клиентов банка

## Описание

`bank_fin.csv` — данные прямого телефонного маркетинга банка: характеристики
клиента, детали контакта в рамках кампании и бинарный результат подписки на
срочный вклад. 11 162 строки, 17 столбцов, разделитель `;`.

## Схема (по факту данных)

**Характеристики клиента:** `age`, `job`, `marital`, `education`, `default`
(есть ли просроченный кредит), `balance` (средний годовой баланс), `housing`
(есть ли ипотека), `loan` (есть ли потребительский кредит)

**Данные последнего контакта / текущей кампании:** `contact` (тип связи),
`day`, `month` (день/месяц последнего контакта), `duration` (длительность
последнего звонка, секунды)

**История кампаний:** `campaign` (число контактов в рамках этой кампании),
`pdays` (дней с последнего контакта прошлой кампании, -1 = ранее не
контактировали), `previous` (число контактов до этой кампании), `poutcome`
(результат предыдущей кампании)

**Таргет:** `deposit` — подписался ли клиент на срочный вклад (`yes`/`no`)

Замечания по данным:
- `balance` в сыром CSV хранится строкой в формате валюты (например,
  `2 343,00 $`) и парсится в число в ноутбуке.
- В `job` есть явная категория `unknown` (70 строк) — замаскированный
  пропуск; ни в одном столбце нет структурного null (`df.isnull().sum()` —
  везде ноль).
- 1 057 строк удалены как выбросы по `balance` методом IQR (границы: -2241…
  4063), остаётся 10 105 строк для моделирования.
