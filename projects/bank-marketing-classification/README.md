# Классификация клиентов банка (срочный вклад)

Бинарная классификация по данным телефонной маркетинговой кампании банка:
предсказать, подпишется ли клиент на срочный вклад (`deposit`: yes/no) по
характеристикам клиента, деталям звонка и истории предыдущих кампаний.

## Задача

Каких клиентов при обзвоне вероятнее всего удастся убедить открыть срочный
вклад, и какие признаки (профиль клиента, канал/время контакта, результат
предыдущей кампании) на это влияют — чтобы банк мог приоритизировать усилия
call-центра на более перспективных клиентах.

## Данные

11 162 записи о клиентах/звонках, 17 столбцов, структурных пропусков нет, но
в столбце `job` есть замаскированная категория `unknown`. Схема и способ
получения — в [`data/README.md`](data/README.md).

## Что сделано

1. **Обзор данных, пропуски, выбросы**: загрузка данных, обнаружение
   скрытой категории `unknown` в `job`, парсинг `balance` из строки в число,
   заполнение пропусков в `balance` медианой, в `job`/`education` — модой,
   удаление выбросов по `balance` методом IQR (удалено 1 057 строк, осталось
   10 105).
2. **EDA**: распределения и описательные статистики по числовым и
   категориальным признакам; доля подписки по результату предыдущей
   кампании, месяцу, возрастной группе, семейному положению, профессии,
   образованию.
3. **Подготовка признаков**: порядковое кодирование `education`/`age_group`,
   бинарное кодирование yes/no-столбцов, one-hot для номинальных признаков,
   проверка мультиколлинеарности, стратифицированное разбиение 67/33, отбор
   15 лучших признаков через `SelectKBest` (`f_classif`), масштабирование
   `MinMaxScaler`.
4. **Логистическая регрессия и деревья решений**: базовая логистическая
   регрессия, дерево решений, подбор `max_depth`/`min_samples_split` через
   `GridSearchCV`.
5. **Ансамбли и важность признаков**: случайный лес, градиентный бустинг,
   стекинг (логистическая регрессия + случайный лес + градиентный бустинг),
   важность признаков по модели градиентного бустинга, подбор
   гиперпараметров случайного леса через Optuna.

## Результаты

| Модель | Метрика на тесте |
|---|---|
| Логистическая регрессия (базовая) | Accuracy 0,81 |
| Дерево решений (`max_depth=6`) | Accuracy 0,81 |
| Дерево решений, подбор `GridSearchCV` (`max_depth=7, min_samples_split=2`) | Accuracy 0,80, F1 0,80 |
| Случайный лес (`n_estimators=1000, max_depth=10`) | Accuracy **0,83** (класс 0: P 0,85/R 0,82/F1 0,84; класс 1: P 0,80/R 0,83/F1 0,82) |
| Градиентный бустинг | F1 0,82 |
| Стекинг (лог-регрессия + RF + GB) | Precision 0,81 |
| Случайный лес, подбор Optuna (20 испытаний; `n_estimators=176, max_depth=25, min_samples_leaf=2`) | Accuracy 0,83, F1 0,82 |

Случайный лес — лучший результат по accuracy среди сравниваемых моделей;
версия с автоматическим подбором через Optuna выходит на практически то же
качество на тесте, просто найденное автоматически.

**Важность признаков** (по модели градиентного бустинга, топ-6 из 15
отобранных):

| Место | Признак | Важность |
|---|---|---:|
| 1 | `duration` (длительность последнего звонка) | 0,507 |
| 2 | `poutcome_success` (предыдущая кампания успешна) | 0,115 |
| 3 | `contact_unknown` | 0,073 |
| 4 | `balance` | 0,058 |
| 5 | `pdays` | 0,055 |
| 6 | `housing` | 0,048 |

**Из EDA**: в мае самая высокая доля отказов (67,9% контактов в мае
заканчиваются «нет» — максимум среди месяцев); клиенты 60+ подписываются в
81,1% случаев против 42–56% в других возрастных группах; если предыдущая
кампания была успешной, повторно подписываются 91,1% клиентов против 39,7%,
когда результат предыдущей кампании неизвестен.

`duration` (длительность звонка) с большим отрывом доминирует по важности,
но этот признак известен только после звонка — для приоритизации клиентов
до звонка его стоит исключать.

## Стек
