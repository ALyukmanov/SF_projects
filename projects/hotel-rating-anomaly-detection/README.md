# Поиск аномальных рейтингов отелей (отзывы Booking.com)

Анализ ~386 тыс. размеченных отзывов Booking.com (плюс ~129 тыс. строк
отложенной выборки без разметки) — можно ли предсказать отображаемый
`average_score` отеля по тексту отзыва, поведению пользователя и метаданным
отеля/поездки. `RandomForestRegressor` обучается предсказывать
`reviewer_score` конкретного отзыва по сформированным признакам. Идея
использования как сигнала о «завышенном рейтинге»: большое и системное
расхождение между предсказанием модели и реальным отображаемым рейтингом
отеля может говорить о том, что рейтинг отеля не соответствует тому, что
предсказывают похожие отзывы и поведение в остальном датасете. Ноутбук
строит и оценивает модель предсказания; сам по себе он не формирует
итоговый список подозрительных отелей — это естественное продолжение.

## Задача

Можно ли по тексту отзыва, истории пользователя и метаданным отеля
предсказать индивидуальную оценку отзыва достаточно точно, чтобы остатки
предсказания служили сигналом о потенциально завышенном или
непоследовательном рейтинге отеля на Booking.com?

## Данные

Датасет соревнования Kaggle «SF Booking Hotels». Сырые CSV
(`hotels_train.csv`, `hotels_test.csv`, `submission.csv`) не хранятся в
репозитории — см. [`data/README.md`](data/README.md) для схемы и способа
получения.

## Что сделано

1. **Разбиение на train/validation/holdout — до препроцессинга.** Отложенная
   выборка Kaggle (без разметки) и 80/20 разбиение размеченных строк
   фиксируются сразу после загрузки сырых данных, до обучения любого
   кодировщика или скейлера. `OrdinalEncoder`, `OneHotEncoder` и
   `MinMaxScaler` обучаются только на обучающей части и затем применяются
   (`transform`) к валидационной и отложенной выборкам — ни одна их
   статистика не берётся из данных, на которых модель потом оценивается.
2. **Подготовка признаков** — признаки уровня отеля (страна из адреса,
   очистка названия), уровня пользователя (нормализация национальности,
   логарифм числа отзывов пользователя), уровня отзыва (разбор тегов на
   цель поездки/тип номера/длительность, число слов, тональность через
   VADER из NLTK).
3. **Отбор признаков** — корреляция Пирсона среди непрерывных признаков,
   корреляция Спирмена среди категориальных/закодированных на
   мультиколлинеарность, ANOVA (`f_classif`, только на обучающей части) для
   ранжирования значимости признаков.
4. **Моделирование** — `RandomForestRegressor(n_estimators=100,
   random_state=42)` на обучающей выборке.
5. **Оценка** — MAPE на отложенной валидационной выборке.

## Результаты

```
MAPE: 12,13
```

По графику важности признаков топ-3 — `review_positive_word_proportion`,
`p_review_sentiments_compound`, `average_score`.

## Стек

Python, pandas, scikit-learn, NLTK (VADER).
