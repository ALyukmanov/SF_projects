# Данные

В этой папке должны лежать четыре CSV-файла с логами событий по группам
A, B, C и таблицей цен товаров. Файлы не входят в репозиторий.

## Файлы

| Файл | Строк | Столбцов | Описание |
|---|---|---|---|
| `sample_a.csv` | 1 188 912 | 3 | Лог событий группы **A** (контроль) |
| `sample_b.csv` | 1 198 438 | 3 | Лог событий группы **B** (тест / новый алгоритм) |
| `sample_c.csv` | 1 205 510 | 3 | Лог событий группы **C** (вторая контрольная, для проверки A/A) |
| `item_prices.csv` | 1 000 | 2 | Таблица цен товаров |

## Схема

`sample_a.csv`, `sample_b.csv`, `sample_c.csv` — одна строка на событие
пользователь/товар:

| Столбец | Тип | Описание |
|---|---|---|
| `user_id` | int | Идентификатор пользователя |
| `item_id` | int | Идентификатор товара |
| `action_id` | int | Код действия: `0` = клик, `1` = просмотр, `2` = покупка |

`item_prices.csv`:

| Столбец | Тип | Описание |
|---|---|---|
| `item_id` | int | Идентификатор товара |
| `item_price` | int | Цена товара, используется для расчёта GMV |
