# Данные

## Источник

Анализ выполняется SQL-запросами напрямую к базе **PostgreSQL**,
предоставленной как часть учебного курса (вакансии/работодатели
HeadHunter). Таблицы: `vacancies`, `employers`, `areas`, `industries`,
`employers_industries`. Подключение задаётся переменными окружения
`DBNAME`, `USER`, `HOST`, `PASSWORD`, `PORT`.

## Схема

### `vacancies`

| Столбец | Роль |
|---|---|
| `id` | первичный ключ |
| `name` | название вакансии (фильтруется через `ILIKE` по ключевым словам) |
| `area_id` | внешний ключ → `areas.id` |
| `employer_id` | внешний ключ → `employers.id` |
| `salary_from` | нижняя граница зарплаты (может быть null) |
| `salary_to` | верхняя граница зарплаты (может быть null) |
| `schedule` | график работы (полный день / удалённо / гибкий и т.д.) |
| `employment` | тип занятости (полная занятость / проектная работа и т.д.) |
| `experience` | требуемый опыт |
| `key_skills` | список ключевых навыков через табуляцию (`CHR(9)`) |

### `employers`

| Столбец | Роль |
|---|---|
| `id` | первичный ключ, связан с `vacancies.employer_id` |
| `name` | название работодателя |
| `area` | внешний ключ → `areas.id` (регион регистрации работодателя) |

### `areas`

| Столбец | Роль |
|---|---|
| `id` | первичный ключ |
| `name` | название региона/города |

### `industries`

| Столбец | Роль |
|---|---|
| `id` | первичный ключ |
| `name` | название отрасли (например, «Разработка программного обеспечения») |

### `employers_industries`

Связующая таблица работодателей и отраслей.

| Столбец | Роль |
|---|---|
| `employer_id` | внешний ключ → `employers.id` |
| `industry_id` | внешний ключ → `industries.id` |

Не добавляйте в эту папку дампы базы, CSV-экспорты или учётные данные.
