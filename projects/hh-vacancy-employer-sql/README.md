# SQL-анализ вакансий и работодателей hh.ru

SQL-анализ базы данных вакансий и работодателей HeadHunter (hh.ru): объём
вакансий, зарплаты, графики работы, концентрация работодателей и отдельный
разбор вакансий Data Science / Data Scientist. Весь анализ — SQL-запросы к
PostgreSQL через `psycopg2` + `pandas`, без резюме и без локальных CSV.

## Задача

Понять рынок вакансий hh.ru: сколько вакансий и работодателей, где они
сконцентрированы, какие зарплаты и условия работы, и отдельно — насколько
велик и требователен сегмент Data Science (объём, требуемые навыки, зарплата
по уровню опыта).

## Данные

База PostgreSQL, предоставленная как часть учебного курса — в репозитории не
хранится (ни CSV, ни дампов). Таблицы: `vacancies`, `employers`, `areas`,
`industries`, `employers_industries`. Схема, восстановленная по фактическим
запросам, — в [`data/README.md`](data/README.md).

Подключение задаётся через переменные окружения (`DBNAME`, `USER`, `HOST`,
`PASSWORD`, `PORT`) — в самом ноутбуке никаких значений этих переменных не
прописано, учётных данных в коде нет.

## Что сделано

Ноутбук разбит на четыре аналитических блока:

1. **Предварительный анализ** — количество строк в `vacancies`, `employers`,
   `areas`, `industries`.
2. **Детальный анализ вакансий** — вакансии по регионам (топ-10 на графике
   Plotly), заполненность и средние значения полей зарплаты, комбинации
   графика и типа занятости, распределение по требуемому опыту.
3. **Анализ работодателей** — лидеры и аутсайдеры по числу вакансий, регионы
   с работодателями, но без вакансий, географический охват работодателей,
   работодатели без указанной отрасли, разбор вакансий Яндекса по городам-
   миллионникам (список городов — из живого запроса к Википедии).
4. **Анализ сегмента Data Science** — вакансии по ключевому слову «data»,
   рабочее определение вакансии Data Scientist/junior DS, SQL/Postgres и
   Python как ключевые навыки, среднее число навыков, средняя зарплата по
   уровню опыта в DS-вакансиях.

## Результаты

- **Объём**: 49 197 вакансий от 23 501 работодателя, 1 362 региона, 294
  отрасли.
- **Концентрация по регионам** (топ-5): Москва 5 333; Санкт-Петербург 2 851;
  Минск 2 112; Новосибирск 2 006; Алматы 1 892.
- **Зарплаты**: у 24 073 вакансий указана хотя бы одна граница зарплаты.
  Средняя нижняя граница ≈ 71 065 ₽, средняя верхняя ≈ 110 537 ₽.
- **График × занятость**: чаще всего — «полный день + полная занятость»
  (35 367 вакансий), затем «удалённо + полная занятость» (7 802), «гибкий
  график + полная занятость» (1 593).
- **Работодатели**: Яндекс — работодатель №1 по числу вакансий, Газпром
  нефть — №5 (запрос вычисляет только эти два места, не полный топ-5).
- **Регионы с работодателями без вакансий**: на первом месте — «Россия», 410
  работодателей (вероятно, указавших страну вместо конкретного региона).
- **Отраслевые данные**: у 8 419 из 23 501 работодателей (≈35,82%) не
  указана отрасль; 3 553 работодателя (≈15,12%) указывают «Разработка
  программного обеспечения».
- **Яндекс в городах-миллионниках**: больше всего вакансий в Москве (54),
  Санкт-Петербурге (42), Екатеринбурге (39), Нижнем Новгороде (36),
  Новосибирске (35).
- **Вакансии, связанные с данными**: 1 771 вакансия (≈3,6% от всех) содержит
  ключевое слово «data»; из них 51 подходит под определение junior/начальный
  Data Scientist.
- **Ключевые навыки DS**: SQL/Postgres встречается в 229 вакансиях, Python —
  в 357; в среднем DS-вакансия перечисляет 6–7 ключевых навыков.
- **Зарплата в DS по опыту**: без опыта ≈74 643 ₽; 1–3 года ≈139 675 ₽; 3–6
  лет ≈243 115 ₽; для «6+ лет» цифра не приводится — по наблюдению
  ноутбука, такие зарплаты обычно обсуждаются индивидуально, а не
  публикуются.

## Стек

Python, psycopg2, pandas, SQL (PostgreSQL), Plotly.
