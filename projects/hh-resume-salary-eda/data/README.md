## Схема (кратко)

`dst-3.0_16_1_hh_database.csv` (разделитель `;`, 44 744 строки в исходном
экспорте) содержит 12 сырых столбцов, каждый из которых объединяет
несколько данных в одном текстовом поле, разбираемом ноутбуком:

- `Пол, возраст` — пол, возраст, дата рождения вместе
- `ЗП` — сумма желаемой зарплаты + валюта
- `Ищет работу на должность:` — желаемая должность
- `Город, переезд, командировки` — город, готовность к переезду и
  командировкам
- `Занятость` — тип(ы) занятости через запятую
- `График` — график(и) работы через запятую
- `Опыт работы` — текстовое описание опыта работы
- `Последнее/нынешнее место работы` — последний/текущий работодатель
- `Последняя/нынешняя должность` — последняя/текущая должность
- `Образование и ВУЗ` — уровень образования + учебное заведение
- `Обновление резюме` — дата последнего обновления резюме
- `Авто` — наличие автомобиля

`ExchangeRates.csv` (разделитель `,`), используемые ноутбуком столбцы:
`currency` (код ISO), `date`, `proportion`, `close`.
