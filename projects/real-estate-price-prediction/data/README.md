# Данные — прогноз цен на недвижимость

Сырые и обработанные файлы данных в этом репозитории не хранятся (см.
`.gitignore` в корне и в проекте, которые исключают `data/raw/*.csv` и
`data/processed/*.csv`).

## Источник

Объявления о продаже квартир по restate.ru (публичные страницы поиска,
HTML-парсинг) — см. `src/data_collection/`. ЦИАН
(`src/data_collection/cian_scraper.py`) когда-то использовался как основной
источник, сейчас недоступен из-за CAPTCHA и оставлен в коде как резервный
вариант. Макроэкономические показатели (ключевая ставка, курс USD/RUB,
инфляция) — из REST API Банка России, через
`src/preprocessing/economic_features.py`.

## Структура директорий

| Путь | Назначение | В git? |
|---|---|---|
| `data/raw/` | Сырые данные скрейпера, один CSV на прогон сбора | Нет — только `.gitkeep` |
| `data/interim/` | Частично очищенные/дедуплицированные объявления до подготовки признаков | Нет — только `.gitkeep` |
| `data/processed/` | Итоговые матрицы признаков (результат `src/features/feature_engineering.py`), готовые к обучению | Нет — только `.gitkeep` |

## Как воспроизвести данные

1. Собрать сырые объявления (нужны интернет и время — см. «Ограничения» в
   README проекта): `python -m src.data_collection scrape --source restate --city moscow`
2. Запустить подготовку признаков: `python scripts/run_feature_engineering_real.py`

Так получится тот же процесс `data/raw/` → `data/interim/` →
`data/processed/`, что описан на диаграмме архитектуры в README проекта.

## Схема (матрица признаков)

Полный список из 27 признаков модели — в разделе «Данные и признаки»
[`MODEL_CARD.md`](../MODEL_CARD.md). `price_per_sqm` присутствует в
обработанных данных для аналитики, но явно исключён из обучения модели
(защита от утечки — этот признак производный от таргета).

## Лицензия / использование

Данные restate.ru собираются только для личного/учебного использования в
портфолио и не распространяются как датасет в этом репозитории.
Макроэкономические данные ЦБ РФ — публичные.
