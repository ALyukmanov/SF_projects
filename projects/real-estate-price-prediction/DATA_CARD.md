# Данные — прогноз цен на недвижимость

## Источник

[restate.ru](https://www.restate.ru) — публичные страницы поиска объявлений
(не API). Сбор — HTML-парсинг с задержками, повторными попытками и
экспоненциальным ожиданием при ошибках (`src/data_collection/`).

ЦИАН (`src/data_collection/cian_scraper.py`) когда-то использовался как
основной источник, сейчас недоступен из-за CAPTCHA и оставлен в коде как
резервный вариант.

## Масштаб

- Собрано: 9 839 объявлений.
- После очистки и удаления дубликатов: **9 720 строк** — Москва (4 931),
  Санкт-Петербург (4 789).
- 7 категорий: студии, 1/2/3-комнатные квартиры, новостройки, комнаты,
  дома/коттеджи.
- Дата сбора: 24–25 августа 2026, один непрерывный проход, 625 страниц
  поиска, без сбоев запросов.

## Координаты и внешние геоданные

- **Координаты объявлений**: страница поиска даёт только город; отдельная
  страница каждого объявления содержит точку карты (`data-lat`/`data-lng`).
  `scripts/enrich_coordinates.py` обходит их по одной (задержка ~2 с, кэш
  `data/raw/restate_details/coordinates.jsonl`). Покрытие: **9 070 / 9 839
  (92,2%)**. Геокодирование address-level — объявления в одном доме часто
  имеют одинаковую точку.
- **Инфраструктура (OSM)**: `scripts/prepare_osm_poi.py` берёт экстракты
  Geofabrik (Центральный + Северо-Западный ФО), разбирает `pyrosm` и
  собирает `data/external/osm_poi.csv` — 27 539 объектов: метро, ж/д
  станции, школы, детсады, поликлиники/больницы, супермаркеты, парки.
  Категория `metro` в OSM смешивает станции и входы; `src/features/geo_features.py`
  схлопывает каждую категорию до объектного уровня. Данные © OpenStreetMap
  contributors, ODbL.
- `data/external/osm_poi.csv` (~2 МБ) и `osm_poi_manifest.json`
  (источник, дата, SHA256 исходных PBF) **хранятся в git** — чтобы
  geo-модель работала сразу после clone. Исходные PBF (~1,5 ГБ,
  `data/external/osm/`) в git **не хранятся**, скачиваются
  `scripts/prepare_osm_poi.py` при пересборке.
  Данные © OpenStreetMap contributors, ODbL —
  <https://www.openstreetmap.org/copyright>.

## Проверки качества

- Диапазонные фильтры по цене, площади, этажу.
- Точное удаление дубликатов по URL объявления.
- Отдельное обнаружение похожих объявлений (одинаковый адрес + число
  комнат + этаж, цена и площадь в пределах 2%) — такие объявления не
  удаляются автоматически (могут быть разными квартирами по одному адресу),
  но учитываются при разбиении на train/test, чтобы не завышать метрику
  модели.

## Пропуски в данных

`rooms`, `floor`, `floors_total` отсутствуют для части объявлений —
структурно, потому что источник не публикует эти поля для категорий
«дома/коттеджи» и «комнаты» (не ошибка сбора). Заполняются медианой по
городу, посчитанной только на обучающей части данных после разбиения на
train/test.

## Что хранится в репозитории, а что нет

- Сырые и промежуточные данные (`data/raw/`, `data/interim/`,
  `data/processed/`) **не публикуются** — только воспроизводятся скрейпером.
- В репозитории — только код сбора/обработки и итоговая обученная модель
  (`models/current_model.json` + сам файл модели).
- Формат и происхождение каждого поля — в
  `src/data_collection/sources/restate.py` и `src/preprocessing/`.

## Ограничения

- Только 2 города (Москва, Санкт-Петербург) — и только для них есть OSM POI.
- Координаты есть у 92,2% объявлений; район в явном виде не собирается.
  Геокодирование address-level (см. «Координаты и внешние геоданные»).
- Год постройки здания почти всегда отсутствует.
- Цена в данных — это цена **объявления** (asking price), а не
  зафиксированная цена сделки.
- Категории «дома/коттеджи» (42 строки на тесте) и «комнаты» (38 строк) —
  маленькие выборки, оценка модели на них менее надёжна (см.
  [`MODEL_CARD.md`](MODEL_CARD.md)).
