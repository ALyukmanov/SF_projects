# Модель — прогноз цен на недвижимость

## Задача

Оценка рыночной стоимости квартиры на вторичном рынке жилья Москвы и
Санкт-Петербурга по базовым параметрам плюс географическому окружению
(расстояния до метро, школ, парков и т.д.). Учебный проект — не заменяет
профессиональную оценку недвижимости.

## Данные и признаки

**45 признаков:**

- 27 базовых: площадь, этаж, этажность, комнаты, возраст здания, соотношение
  этажа к этажности, first/top floor, логарифм площади, плотность комнат,
  взаимодействие комнат и площади, one-hot по городу (8) и типу дома (4),
  макроэкономические показатели (ключевая ставка, курс доллара, инфляция);
- 18 геопризнаков (`src/features/geo_features.py`): расстояние до ближайшего
  метро / ж-д станции / школы / детсада / поликлиники / супермаркета / парка
  (гаверсинус по `BallTree`), количество объектов в радиусе 500 м и 1000 м
  для супермаркетов, школ, детсадов, поликлиник, парков и станций метро,
  флаг `has_coordinates`.

Сырые `latitude`/`longitude` в модель **не входят** — только 18 производных
геопризнаков. Координаты есть у 9070 / 9839 объявлений (92,2%); у остальных
геопризнаки — заглушка и `has_coordinates = 0`, объявления не удаляются.

Таргет — `log1p(price)`, при инференсе обратное преобразование `expm1()`.
Полное происхождение данных — в [`DATA_CARD.md`](DATA_CARD.md).

## Разбиение: по домам (train / CV / holdout)

Геокодирование на уровне адреса: многие объявления в одном доме получают
одну и ту же точку. Разбиение «по похожим объявлениям» разводит только
повторные публикации одного объявления, но разные квартиры в одном доме
могут попасть по обе стороны — модель частично «узнаёт» дом по обучающей
части и holdout завышается.

Поэтому **основное разбиение — по домам** (`build_location_groups`): все
объявления с одной округлённой (4 знака) координатой или взаимно похожие
объединяются в одну группу. 9720 объявлений → 2609 «домов».

- **DEV (80%, 7869 объявлений)** → 4-fold GroupKFold для подбора
  гиперпараметров.
- **FINAL HOLDOUT (20%, 1851 объявление)** → одна финальная оценка. Holdout
  ни разу не участвует в подборе гиперпараметров.
- Seed 42, одно и то же разбиение для всех кандидатов.

Проверка (`scripts/verify_split_leakage.py`): по этому разбиению 0 групп
похожих объявлений и 0 из 1867 «домовых» кластеров (одинаковая координата)
попадают одновременно в train и holdout. Заполнение пропусков в
`rooms`/`total_area`/`floor`/`floors_total` — медианой по городу,
посчитанной только по train-части после разбиения.

## Подбор гиперпараметров

`scripts/tune_models_real.py`, протокол: DEV → 4-fold GroupKFold → выбор по
CV-MAE. Holdout не трогается.

- **XGBoost**: 50 trials Optuna. CV MAE 6 008 424 ± 1 259 718 ₽, CV R² 0,662.
- **RandomForest** (только sanity): 25 trials. CV MAE 6 131 765 ₽, CV R² 0,651.

Результат тюнинга: подобранные на новом разбиении параметры (`max_depth=10`,
`n_estimators=650`) на holdout оказались **хуже** уже использующихся
production-параметров (`max_depth=8`, `n_estimators=600` — подобраны ранее).
Итоговый кандидат использует существующие production-гиперпараметры +
геопризнаки.

## Кандидаты — FINAL location holdout (1851 объявление)

| Кандидат | Признаки | MAE | RMSE | R² | MAPE |
|---|---|---:|---:|---:|---:|
| production_pre_geo | 27, без geo | 6 519 591 ₽ | 11 555 010 ₽ | 0,641 | 26,8% |
| **geo_current_params** | 45, +geo | **5 909 113 ₽** | 10 198 551 ₽ | **0,720** | **23,8%** |
| geo_tuned | 45, +geo (tuned) | 6 142 732 ₽ | 10 627 517 ₽ | 0,696 | 24,5% |

Прирост geo относительно pre-geo: **MAE −9,4%, MAPE −3,0 п.п., R² 0,64 → 0,72.**

### Сравнение с простыми baseline (location holdout, статистики только по train)

| Подход | MAE | R² |
|---|---:|---:|
| Глобальная медиана цены | 12 687 933 ₽ | −0,10 |
| Медиана по городу | 12 443 032 ₽ | −0,11 |
| Цена/м² (глобально) × площадь | 9 246 789 ₽ | 0,41 |
| Цена/м² по городу и категории × площадь | 7 827 916 ₽ | 0,54 |
| **Модель (XGBoost + geo)** | **5 909 113 ₽** | **0,72** |

Модель ниже лучшего простого baseline примерно на **24,5%**
(`1 − 5 909 113 / 7 827 916`). Legacy-gate с жёстким порогом «≥25%» поэтому
остаётся `PROMOTION_READY_WITH_LIMITATIONS`, что не противоречит
geo-specific gate `PROMOTION_READY` — порог там намеренно не фиксирован.

### Для справки — разбиение «по похожим объявлениям» (НЕ основная оценка)

| Кандидат | MAE | R² | MAPE |
|---|---:|---:|---:|
| production_pre_geo | 5 012 052 ₽ | 0,731 | 20,8% |
| geo_current_params | 2 713 581 ₽ | 0,889 | 11,0% |

Это разбиение оптимистично из-за соседей по дому (−46% MAE), поэтому оно
приводится только как дополнительный эксперимент, а не как результат
проекта. Основная оценка — location holdout выше.

## Разбивка по сегментам (location holdout, pre-geo → geo)

| Сегмент | n | MAE pre-geo → geo | MAPE geo |
|---|---:|---:|---:|
| Москва | 1025 | 6 246 243 → 5 972 206 ₽ | 22,2% |
| Санкт-Петербург | 826 | 6 858 793 → 5 830 819 ₽ | 25,7% |
| Цена — нижняя треть | 617 | 2 908 555 → 2 385 318 ₽ | 28,1% |
| Цена — средняя треть | 617 | 4 191 774 → 4 004 082 ₽ | 19,8% |
| Цена — верхняя треть | 617 | 12 458 442 → 11 337 938 ₽ | 23,5% |
| `has_coordinates = 1` | 1691 | 6 645 447 → 5 883 858 ₽ (median AE 3,56 → 3,19 млн) | 23,1% |
| `has_coordinates = 0` | 160 | 5 189 447 → 6 176 024 ₽ (median AE 2,47 → 2,21 млн) | 30,5% |

Оба города и все ценовые сегменты улучшаются. На объявлениях без координат
(160, ~8,6% holdout) средняя ошибка выше на 19%, но это хвост на маленькой
выборке: медианная ошибка и MAPE у geo-модели там **лучше**. Для
`cottages_sale` (32) и `room_sale` (26) остаётся структурная слабость
(источник не публикует комнаты/этаж) — API возвращает
`prediction_reliability: "limited_data"`.

## Feature importance (permutation, location holdout)

Топ-15: `rooms_x_area`, `total_area`, `city_moskva`,
**`nearest_metro_station_distance_m`** (#4), `floors_total`,
**`parks_1000m`** (#6), **`hospitals_1000m`** (#7), `room_density`,
**`nearest_rail_station_distance_m`** (#9), `rooms`, `building_type_brick`,
**`nearest_park_distance_m`** (#12), **`nearest_kindergarten_distance_m`** (#13),
`floor`, `floor_ratio`.

6 из 15 — геопризнаки; расстояние до метро — 4-й по важности. Признаков-
идентификаторов или производных от таргета в матрице нет
(`scripts/compare_geo_uplift.py` — leakage scan).

## Оценочный диапазон

`price_min`/`price_max` в ответе API — не формальный доверительный интервал,
а диапазон по квантилям остатков модели на holdout (`residual_quantile_holdout`).
Наблюдаемое покрытие ≈90% на той же выборке, на которой калибровался.

## Ограничения

- Прогноз — цена **объявления**, а не сделки.
- Только 2 города (Москва, Санкт-Петербург) — для них есть OSM POI.
- Координаты address-level: объявления в одном доме имеют одну точку.
  Оптимистичное разбиение это использует, честная оценка — по домам.
- 7,8% объявлений без координат; для них геопризнаки — заглушка.
- Геопризнаки при инференсе зависят от локального `data/external/osm_poi.csv`
  и актуальности OSM-данных (снимок фиксируется в метаданных артефакта,
  `osm_poi_manifest`). Без этого файла geo-модель отдаёт понятную ошибку
  (503), а не тихо деградирует.
- Возраст здания и макропоказатели почти не варьируются в данных.
- Дома/коттеджи и комнаты — маленькие структурно слабые сегменты.

## Промоушен — geo-модель в рабочих

`scripts/geo_promotion_gate.py` — вердикт **PROMOTION_READY** (9/9 с
`--full-tests`): MAE и MAPE на location holdout лучше pre-geo, оба города без
регресса, no-coord объекты не пострадали по устойчивым метрикам (median AE,
MAPE), утечек нет, схема признаков training/artifact/Predictor совпадает,
inference parity и весь тест-сьют проходят, обучение воспроизводимо.

Рабочий артефакт: **`xgboost_20260909_112549.pkl`**
(`location_grouped_80_20_random_state_42`, `geo_enabled=True`, 45 признаков,
production-гиперпараметры). Промоушен выполнен командами:

```bash
python scripts/run_model_training_real.py --model xgboost --split-strategy location --params-from-manifest
python scripts/promote_model.py --candidate models/xgboost_20260909_112549.pkl --dry-run
python scripts/promote_model.py --candidate models/xgboost_20260909_112549.pkl
```

`promote_model.py` проверяет: версию схемы признаков, точный список и порядок
всех 45 признаков (включая 18 геопризнаков — единый источник истины,
воспроизведение реального пайплайна), наличие обученного imputer,
адекватность метрик, отсутствие абсолютных путей.

**Откат:** предыдущий pre-geo артефакт (`xgboost_20260827_131014.pkl`)
физически сохранён; история — `reports/promotion_log.jsonl`.

```bash
python scripts/promote_model.py --rollback   # вернуться на предыдущий артефакт
```
