# Artem Lyukmanov — портфолио Data Analyst / ML

Учебные и pet-проекты по анализу данных и машинному обучению: от полноценного
ML-сервиса с API и дашбордом до SQL-аналитики, EDA и A/B-тестирования. Ниже —
короткое описание каждого проекта, реальные результаты и ссылки на подробности.

## Основной проект

### Прогноз цен на недвижимость

Оценка рыночной стоимости квартир на вторичном рынке Москвы и
Санкт-Петербурга по реальным объявлениям с restate.ru. 9 720 объявлений
после очистки, собраны скрейпером в августе 2026. У 92% есть координаты — по
ним и объектам OpenStreetMap (метро, школы, парки и т.д.) считаются
геопризнаки. Модель — XGBoost, таргет в логарифмической шкале; оценка на
строгом разбиении **по домам** (объявления с одной координатой целиком в
одну часть, чтобы не завышать метрику). На отложенной выборке (1 851
объявление): MAE 5 909 113 ₽, R² 0,720, MAPE 23,8% — против 6 519 591 ₽ /
0,641 / 26,8% без геопризнаков и ≈ 7,83 млн ₽ у лучшего простого базового
варианта (примерно на 24,5% ниже). Обёрнуто в FastAPI (REST API) и Streamlit
(дашборд), поднимается через Docker.

→ [`projects/real-estate-price-prediction/`](projects/real-estate-price-prediction/)

## Остальные проекты

**A/A/B-тест маркетплейса.** Задача: проверить, обгоняет ли новый алгоритм
ранжирования (группа B) текущий (группа A). Использованы z-тест для долей,
тест Шапиро-Уилка, тест Уэлча и тест Манна-Уитни. Результат: сама
контрольная A/A-пара статистически различается по всем метрикам, поэтому
эксперимент нельзя считать валидным — вывод по группе B честно понижен до
«сигнал, требующий проверки», а не подтверждённый эффект.
→ [`projects/ab-ab-test-marketplace/`](projects/ab-ab-test-marketplace/)

**Классификация клиентов банка.** Задача: предсказать, подпишется ли клиент
на срочный вклад после звонка. Сравнивались логистическая регрессия, деревья
решений, случайный лес, градиентный бустинг и стекинг, подбор
гиперпараметров — Optuna. Лучшая модель (случайный лес) — accuracy 0,83.
Важное ограничение: главный по значимости признак (длительность звонка)
известен только постфактум, поэтому модель в текущем виде не годится для
приоритизации звонков заранее.
→ [`projects/bank-marketing-classification/`](projects/bank-marketing-classification/)

**Сегментация клиентов (RFM).** Задача: разбить клиентов интернет-магазина
на сегменты по покупательскому поведению (Recency/Frequency/Monetary) для
маркетинга. Построены две сегментации — PCA + KMeans (3 сегмента) и t-SNE +
KMeans (7 сегментов), а также классификатор (случайный лес / градиентный
бустинг) для присвоения сегмента новым клиентам без повторного запуска
кластеризации — accuracy 0,98.
→ [`projects/customer-segmentation-rfm/`](projects/customer-segmentation-rfm/)

**EDA резюме hh.ru.** Задача: разведочный анализ — какие признаки резюме
связаны с желаемой зарплатой. Обработка текстовых полей, визуализация,
без построения модели. Медианная желаемая зарплата — 59 000 ₽; готовность к
переезду и командировкам поднимает медиану на 67,5%; на всех уровнях
образования мужчины указывают зарплату на 25–45% выше женщин.
→ [`projects/hh-resume-salary-eda/`](projects/hh-resume-salary-eda/)

**SQL-анализ вакансий hh.ru.** Задача: проанализировать рынок вакансий —
объём, зарплаты, концентрация работодателей, отдельно сегмент Data Science.
SQL-запросы к PostgreSQL через psycopg2. 49 197 вакансий от 23 501
работодателя; зарплата в DS растёт с ≈74,6 тыс. ₽ (без опыта) до ≈243 тыс. ₽
(3–6 лет опыта).
→ [`projects/hh-vacancy-employer-sql/`](projects/hh-vacancy-employer-sql/)

**Поиск аномальных рейтингов отелей.** Задача: можно ли по тексту отзыва и
метаданным предсказать оценку отеля настолько точно, чтобы большие
расхождения сигнализировали о завышенном рейтинге. RandomForestRegressor,
тональность отзывов (NLTK VADER), отбор признаков через ANOVA. MAPE 12,13%
на отложенной выборке.
→ [`projects/hotel-rating-anomaly-detection/`](projects/hotel-rating-anomaly-detection/)

**Длительность поездки такси в Нью-Йорке.** Задача: предсказать длительность
поездки по времени, координатам, погоде и маршруту. Линейные модели,
деревья, случайный лес, градиентный бустинг; таргет в логарифмической шкале.
Лучшая модель — градиентный бустинг, RMSLE 0,39, медианная ошибка 1,8
минуты. Самый тяжёлый датасет в портфолио (~900 МБ).
→ [`projects/nyc-taxi-trip-duration/`](projects/nyc-taxi-trip-duration/)

**Классификация качества вина (SVM).** Задача: определить «хорошее/плохое»
вино по химическому составу и сравнить ядра SVM. StandardScaler + SVC в
одном Pipeline, подбор гиперпараметров через GridSearchCV со стратифицированной
кросс-валидацией. Лучшее ядро — rbf, accuracy 91,6% против 86,6% у базового
варианта (предсказание по частоте класса).
→ [`projects/wine-quality-svm-classification/`](projects/wine-quality-svm-classification/)

**Мониторинг ML-модели в проде.** Задача: показать не только обучение
модели, но и её сопровождение в проде — API, метрики, дашборд,
переобучение без остановки сервиса. FastAPI, RandomForestClassifier,
Prometheus, Grafana, Docker Compose. Accuracy 0,819, F1 0,829; весь стек
поднимается одной командой, дашборд Grafana с 15 панелями.
→ [`projects/wine-quality-model-monitoring/`](projects/wine-quality-model-monitoring/)
